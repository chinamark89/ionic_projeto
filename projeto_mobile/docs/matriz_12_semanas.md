# Matriz de Rastreabilidade - 12 Semanas

## Objetivo
Mapear cada aula para entregas tecnicas concretas no Projeto Master.

| Aula | Tema | Entrega no Projeto Master |
|---|---|---|
| 01 | Introducao ao desenvolvimento mobile | Apresentacao do produto, fluxo geral e visao arquitetural |
| 02 | Configuracao do ambiente | Scaffold Ionic/Angular/Capacitor e execucao inicial |
| 03 | Interfaces - Parte 1 | Layout base e componentes estruturais |
| 04 | Interfaces - Parte 2 | Formularios e validacoes no fluxo de tarefas |
| 05 | Interfaces - Parte 3 | Reuso de componentes Ionic e refinamento visual |
| 06 | Navegacao - Parte 1 | Rotas principais e redirecionamentos |
| 07 | Navegacao - Parte 2 | Tabs e fluxo de navegacao composto |
| 08 | Arquitetura da aplicacao | Organizacao core/features e separacao por responsabilidade |
| 09 | APIs REST - Parte 1 | Service HTTP e consumo de endpoint externo |
| 10 | APIs REST - Parte 2 | Tratamento de erro e feedback com toasts |
| 11 | Persistencia local - Parte 1 | Storage local com Capacitor Preferences |
| 12 | Persistencia local - Parte 2 | Carga inicial e atualizacao de estado persistido com Ionic Storage |
